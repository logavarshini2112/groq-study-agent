# 🤖 Groq Study Agent

An AI-powered study assistant built with **Python, Groq, and the OpenAI SDK**.

This project demonstrates how an AI agent can understand a student's question and decide when to use custom tools such as a calculator and study-note reader.

## 🚀 Features

- 🤖 AI-powered question answering using Groq
- 🧮 Calculator tool for mathematical expressions
- 📚 Read study notes from local files
- 📂 List available study notes
- 🔧 AI tool calling with multiple tools
- 🔐 Environment variables for API key security
- 🐍 Built with Python

## 🛠️ Technologies Used

- Python
- Groq API
- OpenAI Python SDK
- python-dotenv
- Git & GitHub
